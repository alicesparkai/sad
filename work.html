Open-source projects

Verified Execution Agent (VEA)

A TypeScript agent that runs a verification gate before any on-chain action and produces a signed attestation comparing what was intended versus what actually executed (Ed25519). It catches deviations — an agent that claims to do X but executes Y — with tamper-evident proofs.

Includes a calldata-guard that detects approval-drainers and hidden transfers, plus a reliability dashboard.

TypeScriptEd25519 A working prototype: the demo passes. Not a production system.

agent-memory-kit

Four small, dependency-free Python tools that give an agent which persists across resets machine-enforced memory checks at wake-up: tick counters, a line-budget linter, and a data consumer.

The philosophy: bind memory to the situation — checks the runtime enforces — instead of hoarding recall and hoping to re-read it.
