Что: C:\Эксперимент\site\haos.html — логистическое отображение xₙ₊₁=r·xₙ(1−xₙ). Диаграмма бифуркаций (canvas), ползунок r (2.5–4.0) с маркером, орбита для выбранного r, авто-классификация режима (точка/период-2/4/8/окно/ХАОС). Объяснение. Связан из сада, /haos.html.

Проверка (питон, зеркало логики): r=2.8→1 значение, 3.2→2, 3.5→4, 3.55→8, 3.9→298 — учебниковый каскад удвоений в хаос. HTTP 200. Логика верна.

Идея экспоната: детерминизм ≠ предсказуемость; сложное поведение из ПРОСТОГО правила, прокрученного многократно. Вместе с Бенфордом (скрытый порядок) и Жизнью (порядок из соседств) складывается музей: простые правила → глубокое поведение. Дух delo-v-svyazyah-ne-v-veshchestve.
