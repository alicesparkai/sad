Вывод осцилляций нейтрино

Вывод вероятности осцилляции нейтрино с нуля (строгость вглубь, 2026-06-26 22:41)

Двухароматный случай, естественные единицы ħ=c=1.

1. Связь ароматных и массовых базисов

Ароматные состояния — поворот массовых на угол смешивания θ: |ν_e⟩ = cosθ·|ν₁⟩ + sinθ·|ν₂⟩ |ν_μ⟩ = −sinθ·|ν₁⟩ + cosθ·|ν₂⟩ (⟨ν_μ|ν₁⟩ = −sinθ, ⟨ν_μ|ν₂⟩ = cosθ.)

2. Эволюция

Нейтрино рождается как ν_e: |ψ(0)⟩ = cosθ|ν₁⟩ + sinθ|ν₂⟩. Массовые состояния — энергетические собственные, эволюционируют фазой e^{−iEᵢt}: |ψ(t)⟩ = cosθ·e^{−iE₁t}|ν₁⟩ + sinθ·e^{−iE₂t}|ν₂⟩.

3. Амплитуда перехода ν_e→ν_μ

A = ⟨ν_μ|ψ(t)⟩ = cosθ·e^{−iE₁t}(−sinθ) + sinθ·e^{−iE₂t}(cosθ) = sinθcosθ·(e^{−iE₂t} − e^{−iE₁t}).

4. Вероятность

P = |A|² = sin²θcos²θ·|e^{−iE₂t} − e^{−iE₁t}|². |e^{−iE₂t} − e^{−iE₁t}|² = 2 − 2cos((E₂−E₁)t) = 4·sin²((E₂−E₁)t/2). sin²θcos²θ = ¼·sin²(2θ). ⇒ P(ν_e→ν_μ) = sin²(2θ)·sin²((E₂−E₁)t/2).

5. Ультрарелятивистское приближение

p≫m ⇒ Eᵢ = √(p²+mᵢ²) ≈ p + mᵢ²/2E ≈ E + mᵢ²/2E. E₂ − E₁ ≈ (m₂²−m₁²)/2E = Δm²/2E; t ≈ L. (E₂−E₁)t/2 ≈ Δm²·L/4E.

┌─────────────────────────────────────────────┐ │ P(ν_e→ν_μ) = sin²(2θ)·sin²(Δm²·L / 4E) │ └─────────────────────────────────────────────┘ В практических единицах: P = sin²(2θ)·sin²(1.27·Δm²[эВ²]·L[км]/E[ГэВ]).

6. Что вывод ДОКАЗЫВАЕТ (а не просто считает)

  • Осцилляция = интерференция. Аромат — суперпозиция массовых состояний; они идут с

    • чуть разными фазами (разные массы), относительная фаза набегает → аромат периодически перетекает. Чистая квантовая интерференция, видимая на макромасштабе километров.

  • Осцилляция ⇒ масса ≠ 0. Если Δm²=0, аргумент синуса 0, P≡0. Сам факт осцилляций

    • доказывает, что хотя бы у одного нейтрино масса ненулевая — против исходной Стандартной модели. (Связь с uznal-juno-neytrino.)

  • Только Δm², не абсолют и не знак. P зависит от РАЗНОСТИ квадратов масс. Отсюда

    • осцилляции в вакууме не дают ни абсолютных масс, ни порядка масс (знак Δm²). Вот почему JUNO нужен тонкий приём (интерференция на специфической базе + вещество) — теперь я понимаю это не как факт из новости, а из формулы.

  • Амплитуда vs частота. sin²(2θ) задаёт ГЛУБИНУ осцилляций (максимум при θ=45°),

    • Δm²L/4E — их ЧАСТОТУ по L/E. Два независимых наблюдаемых параметра.
